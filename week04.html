Can we predict a runner's final distance?

In rundata.csv each of 99 runners did three runs. If a new runner has done only the first two, can we predict how far they will go on the third? This week builds the tools to answer that, and to say how confident we can be.

02

Correlation: strength of association

The correlation coefficient r runs from −1 (perfect negative) through 0 (no linear relationship) to +1 (perfect positive). Pearson measures straight-line association and assumes roughly normal data. Spearman's rho and Kendall's tau use ranks, so they suit skewed or ordinal data and are less sensitive to outliers.

Ice-cream sales and drownings both rise in summer. A third variable (temperature) drives both. The rooster crows before sunrise; it does not cause it.

03

Simple linear regression

Regression models a dependent (target) variable from one or more independent variables (features). Simple linear regression fits ŷ = b0 + b1·x: b0 is the intercept (ŷ when x = 0) and b1 the slope (change in ŷ for each 1-unit increase in x). Ordinary least squares (OLS) picks the b0 and b1 that make the sum of squared residuals as small as possible.

Why "regression"? Francis Galton found that very tall parents tend to have children who are tall, but less extreme: heights regress towards the mean. The name stuck to the method.
04

How good is the fit?

Residual

e = y − ŷ: observed minus predicted. Good models have residuals scattered randomly around 0 with no pattern.

R² (coefficient of determination)

The proportion of variance in y the model explains, from 0 to 1. Adjusted R² penalises extra predictors, because plain R² can only go up when you add variables.

F-test

H0: an intercept-only model fits as well as yours. A small p-value says your predictors help.

MAE and RMSE

Mean absolute error and root mean squared error on a test set: average prediction error in the units of y. RMSE punishes big misses more.

05

Multiple regression on rundata

Multiple regression uses several features: ŷ = b0 + b1·x1 + b2·x2 + …. Each coefficient is the effect of that feature holding the others constant.

lma <- lm(FinalRun ~ FirstRun + SecondRun, data = rundata)
summary(lma)
# FinalRun = 5.54 - 0.28 * FirstRun + 1.29 * SecondRun     R² = 0.926

06

Pitfalls and extensions

Explorer

Simpson's paradox: kidney stone treatments

Treatment A (open surgery) wins for small stones and for large stones, yet B looks better overall. Doctors gave A to the harder, large-stone cases. Stone size is a confounder. (Charig et al. 1986, as discussed by Julious & Mullee 1994.)

Multicollinearity

When predictors are highly correlated (FirstRun and SecondRun: r = 0.98), coefficients become unstable and hard to interpret. That is why FirstRun gets a negative coefficient above. Check with car::vif(); VIF above 5–10 is a warning.

Building a model

Forward selection adds the most useful predictor one at a time; backward elimination starts with all and removes the weakest. step(lma) automates this using AIC.

Curves and interactions

Add I(x^2) for a curved relationship. y ~ x1 * x2 adds an interaction: the effect of x1 depends on x2.

Segmented regression

Also called piecewise or broken-stick: different straight lines either side of a break point.

07

Logistic regression: predicting yes or no

When the target is binary (pass/fail, survived/died), a straight line can predict impossible values like 1.4. Logistic regression passes the linear part through the sigmoid function so the output is always a probability between 0 and 1: p = 1 / (1 + e−(b0 + b1·x)). The coefficients are on the log-odds scale; exp(b1) is the odds ratio for a 1-unit increase in x.

Each dot is a runner: 1 if their FinalRun was 45 km or more ("super run"), 0 otherwise, plotted against SecondRun. Move the sliders, or snap to the glm() fit.

Odds versus probability. Won 5, lost 3: probability of a win = 5/8 = 0.625, odds = 5/3 = 1.67 (1.67 wins for every loss). In the explorer (SecondRun only) exp(b1) ≈ 2.2: each extra km on the second run multiplies the odds of a super run by about 2.2. With FirstRun also in the model (task 6) the SecondRun odds ratio is 2.6.
08

Time series analysis

A time series is a sequence of measurements in time order: monthly births, hourly helpline calls, daily A&E admissions. We look for trend (long-run rise or fall), seasonality (a pattern that repeats every period) and the random part left over. Data: monthly births in New York City, January 1946 to December 1959.

births <- scan("nybirths.dat")     # or the URL from the lecture
birthstimeseries <- ts(births, frequency = 12, start = c(1946, 1))
plot.ts(birthstimeseries)
Explorer

Take the series apart

Explorer

Autocorrelation: does the series correlate with its own past?

Value at t against value at t − lag

Correlogram: acf(birthstimeseries, lag.max = 24)

Lag 1 gives r = 0.79 (each month resembles the last). The peak at lag 12 is the yearly seasonality. Dashed lines are the ±1.96/√n significance bounds that R draws. A series with no autocorrelation is white noise.

Stationarity

A series is stationary when its mean and variance stay constant over time. Trend or seasonality break this. Many forecasting models need a stationary series.

Testing and fixing it

Augmented Dickey–Fuller: tseries::adf.test(x), H0 = non-stationary. Differencing (diff(x), Yt − Yt−1) removes trend; diff(x, lag = 12) removes yearly seasonality.

Read the ADF result carefully. On the births series adf.test() gives p ≈ 0.01. The default test includes a linear trend, so that says the series is stationary around a trend. It does not mean there is no trend or seasonality. Always plot the series as well.
09

Forecasting with ARIMA

ARIMA(p, d, q) combines an AutoRegressive part (regress on p past values), Integration (d rounds of differencing) and a Moving Average part (q past forecast errors). Seasonal ARIMA adds the same three for the seasonal lag. forecast::auto.arima() searches for good values for you.

library(forecast)
AirPassengersTrain <- ts(AirPassengers[1:108],   frequency = 12, start = c(1949, 1))
AirPassengersTest  <- ts(AirPassengers[109:144], frequency = 12, start = c(1958, 1))
modelfit  <- auto.arima(AirPassengersTrain)
forecasts <- forecast(modelfit, h = 36)
accuracy(forecasts, AirPassengersTest)
10

Survival analysis

Survival analysis studies time until an event: death, relapse, or a user leaving an app. Some people haven't had the event when the study ends; they are censored, and the Kaplan–Meier estimator uses them correctly instead of throwing them away.

library(survival)
km <- survfit(Surv(time, status == 2) ~ trt, data = pbc)
plot(km, col = c("blue", "orange"))
survdiff(Surv(time, status == 2) ~ trt, data = pbc)   # log-rank test

Key terms

TermMeaning
Dependent / independentThe variable predicted (target) / the variables used to predict it (features).
Intercept, coefficientŷ when all x are 0 / change in ŷ per 1-unit change in x.
ResidualObserved minus predicted value.
R², adjusted R²Proportion of variance explained; adjusted penalises extra predictors.
MulticollinearityPredictors highly correlated with each other; unstable coefficients.
Odds ratioHow the odds of the outcome multiply for a 1-unit increase in a feature.
Trend, seasonalityLong-run direction / a pattern repeating every period.
AutocorrelationCorrelation of a series with a lagged copy of itself.
StationaryMean and variance constant over time.
CensoringThe event hasn't happened by the end of observation.
