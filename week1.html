02

What is data?

Data is recorded observations. Most data you analyse in this module is structured: a table where each row is one thing you observed and each column is one property you measured.

Structured

Fits a table: SQL databases, spreadsheets, CSV files. Easy to analyse with R.

Unstructured

Free text, emails, social media posts, doctors' notes, images. Estimated at 80–90% of all data. Needs extra processing (text mining, computer vision).

Quantitative · the "what"

Numbers: temperature, heart rate, Likert ratings. Analysed with descriptive and inferential statistics.

Qualitative · the "why"

Words: interviews, survey comments, app reviews. Analysed with thematic analysis or text analytics.

03

From data to decisions

Data on its own is not useful. Analytics turns it into information, knowledge and finally a decision. The further right you go, the harder the analysis and the more valuable the answer.

04

CRISP-DM: how projects are organised

The Cross-Industry Standard Process for Data Mining has six phases. It is a cycle: what you learn in evaluation often sends you back to the start. Your group project should follow it.

Explorer

Click a phase

A similar process, KDD (knowledge discovery in databases), has five stages: selection, pre-processing, transformation, data mining, interpretation. Expect data cleaning to take most of the time: the often-quoted split is 80% preparing data, 20% modelling.

05

Data wrangling

Wrangling means getting data into the shape and quality your analysis needs: merging datasets, reshaping, combining or discretising variables, filling missing values, cleaning labels.

Explorer

Wide and long formats

The same page-view data in two shapes. Wide is easy to read; long is what most R plotting and modelling functions want.

R and RStudio

Step 1

Install R

From CRAN, cran.r-project.org. This is the language itself plus the base package.

Step 2

Install RStudio Desktop

From posit.co/download/rstudio-desktop. RStudio is the editor you work in; it runs R for you.

R was created for statistical computing (it grew out of the S language from Bell Labs). Python is more general purpose. Both are accepted for the group project.

Key terms

TermMeaning
Variable / featureA measured property; one column of a dataset.
Observation / instanceOne thing measured; one row.
ContinuousNumeric and can take any value in a range (height, time).
DiscreteNumeric counts (number of siblings, number of calls).
Categorical / nominalLabels or groups (campus, blood type). In R: a factor.
CRISP-DMA six-phase cycle for data science projects.
Data wranglingCleaning and reshaping data before analysis.
<-Assignment: store the value on the right in the name on the left.
VectorAn ordered set of values of one type, made with c().
