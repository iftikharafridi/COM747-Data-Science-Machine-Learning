ML Optimisation and Text Mining

How models learn their weights (gradient descent), how we tune their settings (hyperparameters and grid search), and how to turn unstructured text into numbers a model can use.

01

Small gains, many times

British Cycling's "aggregation of marginal gains" improved many small things by 1% each. ML optimisation works the same way: a model improves its weights a little at a time to reduce its error, and we improve its settings a little at a time to raise its accuracy. Text mining then opens up the 80–90% of the world's data that is unstructured.

  • LO1Explain gradient descent, learning rate, and local versus global minima.
  • LO2Distinguish parameters from hyperparameters; tune models with caret grid search, custom grids and oneSE.
  • LO3Pre-process text: tokenise, lowercase, remove stop words, stem or lemmatise.
  • LO4Build a document-term matrix, weight it with tf-idf, and find frequent terms and associations.
  • LO5Describe sentiment analysis, Naive Bayes, topic modelling and word embeddings.
02

Gradient descent: how a model learns its weights

A neural network multiplies each input by a weight, sums them and passes the total through an activation function. Weights start random. A cost function measures the error between predictions and labels. Gradient descent repeatedly nudges each weight a small step downhill on the cost surface: w ← w − learning rate × slope. In a network, back-propagation works out the slope for every weight.

Explorer

Walk downhill

Try a learning rate of 1.0 on the single valley: the steps overshoot and bounce. Start at +3 on the two-valley surface: you settle in the shallow local minimum and never find the deeper one.

Explorer

Gradient descent fits a regression line

Two weights this time: slope m and intercept b for SecondRun = m × FirstRun + b (rundata, features standardised so the steps are well behaved). Each step lowers the mean squared error.

03

Parameters and hyperparameters

Parameters are learned from the data (regression coefficients, network weights). Hyperparameters are settings you choose before training. Tuning means searching for the hyperparameter values that give the best performance on data the model hasn't seen.

04

Grid search with caret

By default caret tries 3 values of each hyperparameter (3p combinations) and resamples each one (bootstrap, 25 times). For C5.0 that is model × winnow × trials = 2 × 2 × 3 = 12 combinations. It keeps the most accurate.

Result

C5.0 on the breast cancer training data

From train(diagnosis ~ ., method = "C5.0", data = trainingData) with set.seed(1) and a 70/30 split. The best setting (outlined) is a boosted tree with 20 trials, winnow off: 95.9% resampled accuracy, 95.3% on the test set. Most settings are within about one point of each other.

selectionFunction = "oneSE"

Instead of the single best, choose the simplest model whose accuracy is within one standard error of the best. Simpler models generalise better. Here oneSE picks rules with 10 trials instead of a tree with 20.

control <- trainControl(method = "cv", number = 10,
                        selectionFunction = "oneSE")
Custom grid

Choose the values yourself with expand.grid() and pass them as tuneGrid. Change the selection metric with metric = "Kappa".

customGrid <- expand.grid(model = c("rules", "tree"),
  trials = c(20, 25, 30, 35, 40), winnow = FALSE)
train(..., tuneGrid = customGrid)
05

Beyond grid search

Random search

Sample combinations at random. Often finds good settings faster than a full grid when only a few hyperparameters matter.

Genetic algorithms

A population of models; keep the fittest (most accurate); combine and mutate their settings to create the next generation; repeat.

Ensembles

Bagging (models on bootstrap samples, vote), boosting (each model fixes the previous one's errors), random forest (bagged trees with random feature subsets).

06

The text-mining pipeline

A collection of documents is a corpus. Before analysis, text is broken into tokens and cleaned. Then each document becomes a row of numbers in a document-term matrix (DTM): one column per word, counting how often it appears. This is the bag of words: word order is lost.

Explorer

Clean three documents and count the words

With the defaults this matches R exactly: DocumentTermMatrix(VCorpus(VectorSource(txt))) lowercases and keeps words of 3+ letters. findFreqTerms(dtm, 3) → course, liked, programming, the.

07

tf-idf: words that characterise a document

"The" appears everywhere, so it says nothing about any one document. tf-idf multiplies a word's frequency in a document (tf) by how rare it is across the corpus: idf = log₂(number of documents ÷ documents containing the word). A word in every document gets idf = 0.

08

Sentiment analysis

Sentiment mining scores text as negative (< 0), neutral (0) or positive (> 0) using a dictionary of word polarities. Better tools such as sentimentr also handle valence shifters: negators ("not happy"), amplifiers ("very happy") and "but" clauses.

Explorer

Score some sentences

A simplified scorer with a small dictionary, negators and amplifiers, to show the idea. R's sentimentr::sentiment() uses a lexicon of about 11,700 words: it gives 0.675 for "I am very happy" and −0.067 for "I am not very happy".

09

Naive Bayes: is this message spam?

Naive Bayes applies Bayes' theorem word by word: P(spam | words) ∝ P(spam) × Π P(word | spam). It is "naive" because it treats every word as independent of the others. It is fast and works well for spam filtering.

Explorer

Classify a text message

Try:
P(spam | message)
prediction

Word counts come from a toy training set of 40 spam and 60 ham messages, with Laplace smoothing (add 1) so unseen words don't make a probability zero. In R: naivebayes::naive_bayes() or e1071::naiveBayes().

10

Topics and word embeddings

Topic modelling with Latent Dirichlet Allocation (LDA) assumes documents on similar topics use similar words, and that each document mixes several topics. You choose k, the number of topics.

Top 10 terms for LDA(AssociatedPress, k = 4) on 2,246 news articles. You name the topics: crime/local news, international politics, economy/business, courts.

One-hot vectors (man = [1,0,0,…]) are huge and treat every pair of words as equally different. Word2vec trains a small neural network (CBOW or skip-gram) so that words used in similar contexts get similar short vectors. Similarity is measured with cosine similarity or Euclidean distance.

Key terms

TermMeaning
Cost functionA measure of error that training tries to minimise.
Learning rateThe size of each gradient descent step.
Local minimumA low point that isn't the lowest overall.
HyperparameterA setting chosen before training (k, trials, C).
Grid searchTrying every combination from a set of hyperparameter values.
CorpusA collection of documents.
Document-term matrixRows = documents, columns = words, cells = counts.
tf-idfTerm frequency × inverse document frequency.
Stop wordsVery common words removed before analysis.
Word embeddingA dense numeric vector representing a word's meaning from its contexts.
