Supervised Machine Learning and Feature Engineering

Teach a computer to label new cases from labelled examples. See why models overfit, how k-nearest neighbours and decision trees make decisions, how to test a model honestly, and how to choose the features that matter.

01

Can a machine learn to diagnose?

The Breast Cancer Wisconsin dataset has 569 tumour samples, each with 30 measurements from a digitised image and a label from a pathologist: B (benign) or M (malignant). A supervised learning algorithm studies the labelled examples and learns a rule that labels new samples. This week you will build and test two such rules.

  • LO1Distinguish supervised, unsupervised, semi-supervised and reinforcement learning; classification and regression.
  • LO2Explain overfitting and the bias–variance trade-off.
  • LO3Build and tune a k-NN classifier, including feature scaling.
  • LO4Explain how a decision tree chooses splits using entropy and information gain; build one with C5.0.
  • LO5Evaluate with train/test splits, cross-validation and confusion-matrix metrics.
  • LO6Select features with filter, wrapper and embedded methods, including Boruta.
02

Types of machine learning

Supervised

Learns from labelled data: each example has the right answer. k-NN, decision trees, logistic regression, SVM, neural networks.

Unsupervised

No labels. Finds structure on its own: clustering (Week 8), association rules (Week 9).

Semi-supervised

A few labelled examples and many unlabelled ones, e.g. cluster first, then label the clusters.

Reinforcement

An agent learns by trial and error from rewards in an environment: game playing, robotics.

ClassificationRegression
PredictsA category (factor): B/M, species, pass/failA number: final run distance, house price
Example methodsk-NN, decision trees, logistic regressionLinear regression, regression trees, k-NN (average of neighbours)
Evaluate withAccuracy, sensitivity, specificity, F1, kappaMAE, RMSE, R²
03

The supervised learning workflow

Where do the labels come from? Is the label a human judgement or a gold-standard test? Was the labeller an expert? Did several people label each case, and how were disagreements resolved? A model can never be better than its labels.
04

Overfitting and generalisation

A model that memorises the training data, noise and all, fits the training set perfectly but fails on new data: overfitting. A model too simple to capture the pattern underfits. The aim is a model that generalises: low error on data it has never seen.

High bias (underfit)

Too simple. Wrong on training and test data. Fix: a more flexible model, better features.

High variance (overfit)

Too flexible. Changes a lot with each new training sample. Fix: more data, simpler model, regularisation, pruning.

05

k-nearest neighbours: "birds of a feather"

k-NN is a lazy learner: it doesn't build a model in advance. To classify a new case it finds the k closest training cases (usually by Euclidean distance, √Σ(ai − bi)²) and takes a majority vote. Use an odd k to avoid ties. Because it uses distances, features on bigger scales dominate, so standardise (scale()) or normalise (min–max) first.

Explorer

Classify an iris

Click anywhere in the plot to place a new flower. The shaded background shows what k-NN would predict at every point (the decision regions).

06

Decision trees

A decision tree is an upside-down flowchart of yes/no questions. Starting at the root, it splits the data on the feature and threshold that best separates the classes, then repeats inside each branch (recursive partitioning) until the leaves are pure enough. Trees are easy to explain and do their own feature selection.

Entropy (impurity)

−Σ p·log₂(p). 0 for a pure group, 1 for a 50/50 mix of two classes.

Information gain

Entropy before the split minus the weighted entropy after. The tree picks the split with the biggest gain.

texture_mean overlaps a lot, so even its best split gains little. concave.points_worst separates the classes well, which is why real trees choose it first.

Trees: C4.5, C5.0, CART (rpart), ID3. Boosting (C5.0(..., trials = 10)) builds many trees, each concentrating on the cases the previous ones got wrong, and lets them vote. A random forest averages many trees grown on bootstrap samples.
07

Testing a model honestly

Explorer

Hold-out split and k-fold cross-validation

Hold-out

60/40, 70/30, 80/20 or 90/10. Quick, but the score depends on which cases happen to land in the test set.

k-fold CV

Every case is tested exactly once. Report the mean accuracy across folds ± its standard error.

LOOCV

k = n. Best for small datasets (trains on n − 1 cases), but builds n models.

The confusion matrix

Accuracy can mislead. If 95% of patients are healthy, a model that always says "healthy" scores 95% accuracy and finds no disease at all. Sensitivity and specificity don't depend on how common the disease is. Balance the classes (undersample the majority, oversample the minority, or SMOTE in Week 6) and report several metrics.
09

Feature engineering and selection

Feature extraction creates features from raw data: amplitudes and intervals from an ECG, a "bag of visual words" from an image. Feature selection keeps the features that help, because extra features cost money to collect, slow training and can add noise.

Independent featuresDrop one of each highly correlated paircor(); caret::findCorrelation()

Key terms

TermMeaning
Label / ground truthThe correct answer attached to each training example.
FeatureAn input variable used to predict the label.
OverfittingLearning the noise in the training data; poor on new data.
Lazy learnerDefers all work until prediction time (k-NN).
Entropy, information gainImpurity of a group; reduction in impurity from a split.
Cross-validationRotating which part of the data is the test set.
Sensitivity / specificityTrue positive rate / true negative rate.
Precision / F1Share of positive predictions that are right / harmonic mean of precision and sensitivity.
Class imbalanceMany more cases in one class than another.
Shadow featureA shuffled copy of a feature, used by Boruta as a baseline.
