COM747 R Labs - student website (Weeks 1-4)

index.html      Home page linking all weeks, notebooks and datasets
week1-4.html    Student lab pages (self-contained: open directly in any browser)
data/           rundata.csv, student_data.csv
notebooks/      Knitted worked notebooks (HTML)

GitHub Pages: create a repository, upload the CONTENTS of this folder,
then Settings > Pages > Deploy from branch (main, / root).

Blackboard: upload the zip as a content package / "Upload ZIP and unpack",
and link to index.html. Keep the folder structure so the data/ and
notebooks/ links work. A single weekN.html also works on its own,
but its dataset links then need the CSVs uploaded alongside in data/.
