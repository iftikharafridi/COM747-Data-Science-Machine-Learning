COM747 Data Science & Machine Learning - student website (Weeks 1-12)

index.html       Home page: weeks, notebooks, datasets, assessment
week01.html ...  Interactive lecture reference pages (Week 2 has parts A and B).
week12.html      Every page has the left-hand week menu, explorers, R tasks
                 with answers, a quiz and a self-check. Each page is
                 self-contained and opens directly in a browser.
notebooks/       Knitted R notebooks (HTML): lecture demonstrations and
                 complete seminar solutions for every week
data/            CSV files used in the labs (rundata, student_data, titanic,
                 data.csv = Breast Cancer Wisconsin, Iris, nybirths ...)

GitHub Pages: create a repository, upload the CONTENTS of this folder,
then Settings > Pages > Deploy from branch (main, / root).

Blackboard: "Upload ZIP and unpack" (or a content package) and link to
index.html. Keep the folder structure so the menu, data/ and notebooks/
links work.

Fonts load from Google Fonts when online; pages fall back to system fonts
offline. Self-check ratings are stored only in each student's browser.
