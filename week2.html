03

Filtering: asking questions of a vector

Filtering happens in two steps. A comparison such as marks < 40 produces a logical vector: one TRUE or FALSE for each student. Putting that inside square brackets keeps only the TRUE positions.

Explorer

Build a filter

Quick picks:
Values or positions? marks[marks < 40] gives the marks (what they scored). which(marks < 40) gives the positions (which students). sum(marks < 40) counts them, because TRUE counts as 1.
Recoding
x <- c(5, 2, 3, 8)
x[x > 4] <- 0
x   # 0 2 3 0

Change only the values that meet a condition.

subset() and NA
x <- c(1:10, NA)
x[x > 5]          # 6 7 8 9 10 NA
subset(x, x > 5)  # 6 7 8 9 10

subset() drops missing values for you.

04

Data types and coercion

R has five atomic classes: logical, integer, numeric (double), complex and character. A vector holds only one type. If you mix types, R silently converts everything to the most flexible one. This is implicit coercion.

05

Vectorisation and recycling

Three principles make R code short: vectorisation (functions work on every element at once), filtering (sub-vectors with [ ]), and recycling (a shorter vector is repeated to match a longer one).

sample() with and without replacement

Drawing 10 values from 1:10. Without replacement it is a shuffle: no repeats. With replacement, values can repeat and some never appear. This is bootstrapping.

Explorer

How a matrix is filled

R fills a matrix column by column (column-major order) unless you say byrow = TRUE.

Missing values. mean(c(1, 2, NA)) returns NA. Use mean(x, na.rm = TRUE), find them with is.na(x), or fill them: x[is.na(x)] <- mean(x, na.rm = TRUE).

12

Key terms

TermMeaning
Logical vectorTRUE/FALSE values, one per element, from a comparison.
Filtering / subsettingKeeping elements where a condition is TRUE: x[x < 40].
IndexA position in a vector. R counts from 1.
RobustNot pulled around much by extreme values (the median is robust; the mean is not).
CoercionConverting between types, automatically (implicit) or with as.*() (explicit).
VectorisationA function acting on every element at once.
RecyclingRepeating a shorter vector to match a longer one.
BootstrappingSampling with replacement: sample(x, n, replace = TRUE).
FactorR's type for categorical data, with fixed levels.
Data frameA table: equal-length columns, each with its own type.
