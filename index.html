COM747 R Labs

Weekly lab pages for the statistics and R half of the module. Each week has the key ideas, interactive explorers, and R tasks at three levels with answers you can check yourself.

How to use these pages

In class

Keep RStudio open beside the page. Predict what each line will print before you run it.

Explorers

Move the sliders and change the numbers. Each explorer shows the R code that gives the same answer.

R tasks

Start with Core, then Challenge, then Stretch. Open the hint before the answer.

Assessment

Coursework 1 · 40%

Practical skills test

90 minutes in the lab, open book (module materials and your own notes only). Load a dataset in RStudio and answer questions with R. Covers Weeks 1–6, so every task on these pages is practice for it.

Coursework 2 · 60%

Group data science project

An open dataset, a full CRISP-DM lifecycle, a 4-page IEEE paper, plus an individual video and code summary. Week 3's EDA and Week 4's tests belong in the methods and results.
