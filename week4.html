02

Population and sample

Almost every dataset is a sample, not the whole population. Statistics calculated from a sample (the sample mean) estimate population parameters (the true mean). Different samples give different estimates: that variation is sampling error. Bigger random samples give estimates closer to the truth: the law of large numbers.

03

Standard error and confidence intervals

Standard error

SE = sd / sqrt(n)

How far a sample mean typically lands from the true mean. Quadruple n to halve it.

95% confidence interval

mean ± t × SE

t ≈ 1.96 for large n. For small n use qt(0.975, n - 1): 2.145 when n = 15.

Lecture example: mean 75, SD 18, n = 36. SE = 18 / 6 = 3. 95% CI = 75 ± 1.96 × 3 = 69.12 to 80.88. Report it as "75 (95% CI 69.12, 80.88)".

04

The hypothesis-testing recipe

  1. 1State the hypotheses. H0: there is no difference (dogs are not faster than mice). H1: there is a difference.
  2. 2Choose alpha, usually 0.05: the false-positive rate you will accept.
  3. 3Check assumptions. Normality: shapiro.test(). Equal variances: largest ÷ smallest variance below 1.5, or var.test().
  4. 4Run the test to get a test statistic (t, χ², F) and a p-value.
  5. 5Decide and report. If p < alpha, reject H0. Always add the effect size and a confidence interval.
The p-value is the probability of a result at least this extreme if H0 were true. It is not the probability that H0 is true, and a big p-value does not prove there is no effect.

07

Multiple testing

Data mining runs many tests. With alpha = 0.05, each test where nothing is going on still has a 1 in 20 chance of a false positive, so the chance of at least one false discovery climbs quickly. The Bonferroni correction divides alpha by the number of tests.

Key terms

TermMeaning
Sampling errorThe difference between a sample statistic and the true population value.
Standard errorThe SD of sample means: sd / √n.
Confidence intervalA range that would contain the true value in 95% of repeated studies.
Degrees of freedomSample size minus parameters estimated; n − 1 for one mean.
H0 / H1Null hypothesis (no effect) / alternative hypothesis.
p-valueChance of a result at least this extreme if H0 were true.
AlphaThe Type I error rate you accept; the cut-off for p.
PowerChance of detecting a real effect: 1 − β.
Cohen's dDifference in means in pooled-SD units: an effect size.
BonferroniDivide alpha by the number of tests.
